魔兽争霸III「流畅指挥」  安装说明
================================================

一、这个包是做什么的
------------------------------------------------
装上之后，框一大片单位点过去，单位能更早开始动，不用再干等。

  场上 240 个单位在动，单点其中一个：
      原版 4.2 秒  ->  装上之后 0.3 秒

仅支持单机。请不要用于对战平台或任何联机对战。


二、安装前请确认
------------------------------------------------
- 系统：Windows
- 游戏版本：1.24b / 1.24e / 1.25b / 1.26 / 1.27a
  （在魔兽目录里右键 Game.dll -> 属性 -> 详细信息，看"文件版本"）
- 知道你的魔兽争霸III 装在哪个文件夹
  （就是里面有 War3.exe 的那个文件夹）


三、安装步骤
------------------------------------------------
1. 先完全退出魔兽争霸III。

2. 解压本 zip 到任意位置（比如桌面）。

3. 双击运行  War3_SmoothCommand_Setup.exe

4. 安装向导会问你装在哪个文件夹：
   请选择魔兽争霸III 的**根目录**，
   也就是里面能看到 War3.exe 的那个文件夹。
   选错的话装完不会生效。

5. 按提示装完即可。


四、怎么用
------------------------------------------------
装完之后，**直接双击你原来那个魔兽图标启动游戏**就行，
不需要再运行任何程序。

如果没生效，试试：
  - 把魔兽完全退出，再启动一次；或
  - 双击魔兽目录里的 Start-War3-Unlock.bat 启动。


五、怎么确认装上了
------------------------------------------------
看魔兽目录下的 patch\SlotPatch.log，用记事本打开，
里面有这样一行就说明成功了：

  slot patch applied (1.24e (Game.dll 1.24.4.6387)): 4/4 sites

（4/4 或 8/8 都算成功，数字对应你的游戏版本。）

注意：Game.dll 是进入地图时才加载的，所以刚启动、还停在
主菜单时，日志里可能还没有这行；进一张图之后再来看。


六、安装过程中改了哪些文件
------------------------------------------------
只会动魔兽目录里这一个文件：

  ijl15.dll    （原版会被改名为 ijl15_orig.dll 保留）

另外会在魔兽目录下新增 patch 文件夹（放补丁本体）。
游戏本体、存档、地图都不会被改动。


七、卸载
------------------------------------------------
控制面板 -> 程序和功能 -> 找到「流畅指挥」-> 卸载。

卸载会自动把 ijl15.dll 还原成原版，并删除新增的文件，
不会动游戏本体。


八、杀毒软件报警怎么办
------------------------------------------------
本工具需要读写魔兽进程的内存才能生效（这是所有同类补丁的
工作方式），可能被部分杀毒软件或 SmartScreen 误报。

- 本项目不含任何联网、后门、数据收集行为，源码随包附带；
- 如不放心，请先核对 SHA256SUMS.txt 里的校验值；
- 如果仍然不放心，请不要使用。


九、常见问题
------------------------------------------------
Q1 会不会被封号？
   它自己不联网，但对战平台可能把内存改动判为篡改，
   所以别在平台上用。

Q2 支持哪些版本？
   1.24b / 1.24e / 1.25b / 1.26 / 1.27a，安装包会自动识别。
   其它版本装不上效果，但也不会弄坏游戏。

Q3 狂点移动命令会更快吗？
   不会，反而更慢。重复下令会让单位重新排队。

Q4 最多能带多少单位？
   500–700 个比较舒服；1000 左右还是会开始明显排队。

Q5 怎么核对文件完好？
   PowerShell 里执行：
     Get-FileHash War3_SmoothCommand_Setup.exe -Algorithm SHA256
   和 SHA256SUMS.txt 里的值一致即可。
